Lorugum Guest House phone app (installable web app)

1. Upload all files in this folder to any HTTPS web host (Netlify Drop, GitHub Pages, Cloudflare Pages, or your own site).
2. Open the address on the phone.
   Android (Chrome): menu > Install app / Add to Home screen.
   iPhone (Safari): Share > Add to Home Screen.
3. It then opens full screen like a normal app and works without internet.

Records are stored on each phone. Use Dashboard > Save backup regularly.
